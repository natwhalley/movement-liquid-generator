# Movement Liquid Code Generator

Generate personalized Liquid code for Movement email campaigns without writing code.

## Live Demo

Running locally at: http://localhost:5173

## Features

- 🎯 Plain English to Liquid code
- 👁️ Live preview with realistic supporter profiles
- ✅ Automatic validation and formatting
- 📋 One-click copy to clipboard
- 💡 Pre-built templates for common use cases

## How to Use

1. **Choose an example** from the left sidebar, or
2. **Describe what you want** in plain English
3. **Click "Generate Liquid Code"**
4. **Preview** with different supporter profiles
5. **Copy** and paste into Movement's email builder

## Example Prompts

- "show people's most recent donation amount, but if it's under £2 show a 2x multiplier amount instead"
- "thank active regular donors, ask cancelled donors to restart, and ask non-donors to join"
- "ask for £10 more than their highest donation, or £5 if they've never donated"

## Running Locally
```bash
npm install
npm run dev
```
